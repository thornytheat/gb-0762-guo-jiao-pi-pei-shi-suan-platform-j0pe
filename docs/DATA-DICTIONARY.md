# 化验批、试配约束与库存定义

`assays.csv` 必填 `lot,expires,stock,unit,moisture_pct,gel_sag`，列序可变。批号为原形字符串。有效期记日历日期 `YYYY-MM-DD`，到期日当日仍可用。日粒度按试配记录所在工厂日历解释。`stock` 为 g 或 kg，统一成整克。水分按百分数录入，保留至 0.01%；凝胶度为 SAG，可录至千分之一。UTF-8 允许首行 BOM。数值接受合法千分位及全角数字。空单元格、空值哨兵、JSON null 分别由相应校验识别。

空文件、全空行、仅表头分别有 `EMPTY_FILE`、`BLANK_FILE`、`HEADER_ONLY`。原件行号是记录起始物理行，原值保留。相同批号按归一日期、库存、水分、凝胶度比较，相同保留首个来源，冲突整组隔离。每份 CSV 至多 250,000 字符。

计划 `as_of` 为试配日，`target_g` 和 `step_g` 为正整数。前者必须可被后者整除，且领用步数最多 60。`dry_min_g` 为干物下限，`gel_low_sag` 和 `gel_high_sag` 均含界。可选 `proposal` 是批号到非负整克的映射；合桶号也可作为键，按整桶复验值计入干物与凝胶。公式用万分克整数累计干物，乘毫 SAG 得凝胶矩，精确叉乘验上下限，展示值四舍五入为 3 位小数。

## 合桶复验 `drums`

可选 `drums` 是合桶复验单数组，每项：

```json
{"drum":"D-01", "created":"2026-11-15",
 "sources":[{"lot":"R-01","grams":3000},{"lot":"R-02","grams":2000}],
 "recheck":{"moisture_pct":"4.5","gel_sag":"153","verdict":"PASS"}}
```

- `drum` 桶号，不得与采信批号同名，数组内不得重复；`created` 可选，须为合法日期。
- `sources` 非空，每项恰好 `lot`、`grams`；同一原批重复出现时合并，来源合计为正整数克。
- `recheck` 恰好 `moisture_pct`、`gel_sag`、`verdict`。水分按百分数、SAG 可至千分之一，规则同化验值。`verdict` 接受 `PASS`/`FAIL`/`合格`/`不合格`（大小写与首尾空格不敏感）。
- 复验值只属于整桶，不摊回原批。

判定顺序固定为：来源可核对 → 复验结论 → 原批有效期。状态：

| 状态 | 含义 | 可领 |
|---|---|---|
| `REUSABLE` | 复验合格，所有来源原批在试配日仍有效 | 桶重减账本已领 |
| `REJECTED` | 整桶复验不合格 | 0 |
| `EXPIRED_SOURCE` | 复验合格，但至少一份来源原批已到期 | 0（整桶卡住） |
| `INVALID` | 来源批号不可核对、来源克重超出原批、桶号撞批号 | 0 |

`INVALID` 不转出原批库存，其余状态按提交序把来源克重从原批转出且只转一次；同一原批被多桶引用而超出余量时，后到桶判 `INVALID`（`OVER_SOURCE`）。桶有效期取来源原批到期日的最早值。

## 领用账本 `POST /api/issues`

请求体在试配资料外增加 `drum`、`grams`、`key`。`grams` 为正整数克，`key` 为 1–128 字符提交单号。服务在账本目录文件锁内依次「读全账本 → 重算可领量 → 校验 → 原子发布」：

- 两单并发提交同一桶，只有能容纳的单会成功，其余返回 `409 OVER_DRUM`，不会领超。
- 失败单不落盘，同单号重试不会重复扣余料。
- 同 `key`、同桶同克重同试配日重放返回既有记录与 `created:false`；同 `key` 不同内容返回 `409 IDEMPOTENCY_CONFLICT`。
- 非 `REUSABLE` 桶返回 `422 DRUM_NOT_REUSABLE`，未知桶返回 `404 DRUM_NOT_FOUND`。

领用记录保存桶号、克重、复验结论、桶有效期、来源清单与按来源克重分摊的原批追溯（最大余数法，分摊合计恰等于领用克重）。账本已领量只影响可领量，不改写回用判定。

## 寻优、结算与留档

寻优用到期日、批号排序，以最少领用批为首要目标，同批数优先最大化较早批次的用量。桶作为不可拆分的库存单元参与寻优，其到期日为来源最早到期日。超出 14 个可用整步批或 300,000 状态上限时报错。不可行时整单留待处理，库存保持原量。

结算以原批期初为唯一起点：合入桶的料记为 `drummed_g` 从原批转出，之后只在桶行领用，守恒式为 期初 = 本单领用 + 账本已领 + 期末，合桶前后重量只算一次。结算库存包含已采信但过期与不足整步的库存，冲突批计入隔离清单。

同份化验文本、同计划、同提案、同合桶复验单、同账本上限计算同一 SHA-256 标识。运行保存源摘要、计划、候选提案、合桶单、账本上限、UTC 建立时间、耗时、规则和逐阶段证据。归档经同目录临时文件写入和原子发布，重复提交返回既有快照。证据摘要以排序键、UTF-8 和紧凑 JSON 复算。
